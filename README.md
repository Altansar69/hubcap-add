# Hubcap (Millennium plugin)

Adds games to your Steam library straight from their store page.

## Requirements

- [Millennium](https://steambrew.app/) (Lua backend)
- A HubcapTool `config.yaml` at `<Steam>/config/hubcaptools/config.yaml` with `HubcapApiKey` and `HubcapLuaDir`

## Install

Copy this folder into `<Steam>/millennium/plugins/hubcap-add` and enable it in Millennium.
